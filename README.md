# rainman

Cimetière d’hypothèses et journal d’exploration autour de la **conjecture de Riemann**.

> **RH reste ouverte.**  
> Ce dépôt ne contient **pas** de preuve. Il documente un triage : ce qui est mort comme route de preuve, ce qui reste vivant, et ce que les calculs ont montré.

## Mission

1. Trier les pistes (équivalences, affaiblissements, faux amis, programmes structurels)
2. Tester par le calcul quand c’est possible
3. **Enterrer vite** les routes fausses ou trompeuses
4. Archiver décisions, status, découvertes
